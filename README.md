# County Election and Turnout Map

A static, accessible county map of Colorado's certified 2022 Governor and 2024 President results and voter turnout. This is an unofficial capstone project, not a government service.

## Run locally

Use Node.js 22 or later. The repository includes generated public data; viewing the site does not require Python or rebuilding the source files.

```sh
npm run serve
```

Open the local URL printed by the server. Viewing the prebuilt site needs no dependency installation. Files must be served over HTTP rather than opened with `file://`, because the application uses JavaScript modules and fetches JSON.

## Rebuild official data

The build uses Node.js, mapshaper, SheetJS, and Python with pdfplumber for the 2024 PDF abstract. See [the maintainer guide](docs/maintainer-guide.md) for setup, source provenance, validation and updates.

```sh
npm run build -- co
npm test
```

Turnout is ballots cast divided by active registered voters. Candidate shares use votes cast in the selected race. Margin is the leading candidate's share minus the runner-up's share. Calculations retain full precision; the interface displays one decimal place.

## Project structure

- `index.html`, `css/`, `js/`, `vendor/d3.min.js`: static website.
- `data/`: validated public JSON and county geometry generated by the build.
- `states/`: state configuration, unchanged official input files and provenance.
- `build/`: source adapters, normalization, calculations, validation and publication.
- `docs/specifications/`: the three controlling capstone documents and extracted review text.
- `docs/data-contract.md`: shared browser/build schema.
- `docs/acceptance-checklist.md`: requirement-by-requirement verification plan.
- `docs/verification.md`: checks performed, measured results and remaining manual acceptance.

Other states and primary contests are supported by configuration and adapters, but their real data is outside the initial release. Precinct-level display, additional races, demographics and trend charts are outside scope.

## Hosting

The design targets GitHub Pages with HTTPS. No deployment is performed automatically. The site uses relative asset paths for repository subpaths, serves D3 locally, and has no application backend, cookies, analytics or persistent browser storage. See the maintainer guide before preparing a public deployment.
